## Installation
```bash
pip install git+https://github.com/CoolCat467/Survival-Simulation.git
```
or
```bash
git clone https://github.com/CoolCat467/Survival-Simulation.git
cd Survival-Simulation
pip install -e .
```

## Usage
```bash
survival_sim_run --help
```

Saved survivor models are currently stored inside the installation
script directory in the `survivor_data` folder
